# Shahid TV – مشروع تطبيق أندرويد (APK) للتلفاز والهاتف

التطبيق عبارة عن غلاف (WebView) يفتح موقعك المنشور بملء الشاشة، ويعمل على Android TV (بالريموت) وعلى الهاتف.

## قبل البناء: انشر الموقع
الموقع يحتاج خادماً (دوال السيرفر + Supabase + /api/play)، لذلك يجب أن يكون منشوراً على رابط ثابت (Lovable أو سيرفرك).
افتح `gradle.properties` وغيّر:
    siteUrl=https://رابط-موقعك
(يمكن أيضاً تغييره من داخل التطبيق بزر MENU في الريموت.)

## طريقة 1: Android Studio
1. File ▸ Open ▸ اختر هذا المجلد، وانتظر Sync (JDK 17).
2. Build ▸ Build APK(s).
3. الملف: `app/build/outputs/apk/debug/app-debug.apk`

## طريقة 2: بدون Android Studio (GitHub)
ارفع المجلد إلى مستودع GitHub، ثم Actions ▸ Build APK ▸ Run workflow، ونزّل الـ APK من Artifacts.

## التثبيت على التلفاز
انسخ الـ APK على USB أو استعمل تطبيق Downloader، أو `adb install app-debug.apk`.

## الأزرار
- MENU: تغيير رابط الموقع
- Play/Pause: تشغيل/إيقاف الفيديو
- BACK: رجوع / خروج من ملء الشاشة

## ملاحظات
- لوحة التحكم `/admin` تُفتح من متصفح الحاسوب وليس من التطبيق (لا تعطِ المشتركين رابطها).
- التنقل بالريموت يعتمد على التركيز (focus) داخل الصفحة؛ قد تحتاج لتحسين `watch.tsx` ليتناسب مع D-pad.
- صيغ MKV/AC3 قد لا تعمل داخل WebView؛ استعمل المشغّل الخارجي (VLC/MX) الموجود في موقعك عند الحاجة.
- الإصدار الحالي debug. للنشر على المتاجر يلزم توقيع release.
